Four ways in

A site being moved off WordPress is very often half-broken. Every source produces the same records, so the mapping you build does not change with the connection you happen to have.

MySQL database Everything A live database, a tunnel, or a restored dump. The only complete source.
WXR export file Content, terms, users No credentials, no network. Works on a site that is already switched off.
REST API What REST exposes Easiest to set up, weakest data. Parity with wp-import.
wp-cli over SSH Everything A managed host that gives you a shell but not a database port.
