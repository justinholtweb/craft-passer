# Plugin Store promo images

Marketing images for the Passer listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-passer](https://justinholt.com/plugins/craft-passer).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `passer-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

screenshot slides can be added alongside these without redoing anything.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin page's: accent `#7492C4`, deep `#4C6EA8`, warm `#2FA39B`, Jersey 20 for display,
Inter for body.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — road, centre line, arrow and cars, with the rounded tile stripped off. The
  full icon's tile is ~70px of solid colour at watermark scale and reads as a hard-edged box
  across the slide, which is why the frame is stripped rather than the whole icon being faded
  further.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.

## Trade marks

Passer names WordPress, WooCommerce and a dozen third-party plugins, so the cover slide carries the
disclaimer that it is not affiliated with or endorsed by any of them. Keep it if you re-cut the
deck — the same line appears in the page footer on justinholt.com.
